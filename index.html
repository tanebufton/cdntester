Live monitor — latency, jitter, loss & route changes

Continuously probes the selected targets like a browser-based ping. Watches for POP changes mid-session (route flaps, failover, anycast shifts), and reports jitter and packet loss (timeouts after 5s count as loss). Samples reuse an open connection so they approximate pure edge response time.

Speed, jitter & bufferbloat

Uses Cloudflare's public speed-test endpoints (speed.cloudflare.com). Measures idle latency and jitter, download and upload throughput, and latency under load to grade bufferbloat. This tests your path to the nearest Cloudflare POP, not to every CDN.

Throughput to any URL

DNS & resolver steering
